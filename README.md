# ENI-Enchères

## Présentation du projet

**ENI-Enchères** est une application web développée en Java dans le cadre de ma formation à l’ENI École Informatique.

Le projet consiste à développer une plateforme de ventes aux enchères permettant aux utilisateurs de consulter des articles, de participer aux ventes et de gérer leurs enchères.

Le développement s’appuie sur un cahier des charges fonctionnel, des documents de conception et un modèle de base de données fournis au démarrage du projet.

## Fonctionnalités

Les fonctionnalités sont développées progressivement selon les priorités définies dans le document de spécifications fonctionnelles.

Le projet couvre les fonctionnalités prévues dans les différentes itérations, en fonction de l’avancement du développement.

## Technologies utilisées

- **Java** : développement de la logique applicative.
- **HTML** : structuration des pages web.
- **CSS** : mise en forme et présentation de l’interface utilisateur.

## Conception

Le développement s’appuie sur les documents fournis :

- Document de vision du projet
- Description des fonctionnalités priorisées par itération
- Diagramme de classes du domaine
- Diagramme d’état du cycle de vie d’une vente
- Script de création de la base de données

## Installation

1. Cloner le dépôt Git :

   ```bash
   git clone https://github.com/audrey-pe/Encheres.git
   ```

2. Ouvrir le projet dans un environnement de développement compatible avec Java.

3. Configurer la base de données selon les paramètres du projet et exécuter le script SQL fourni.

4. Configurer les éventuelles dépendances et les paramètres de connexion à la base de données.

5. Compiler et lancer l’application selon la configuration du projet.

## Contexte

Projet réalisé dans le cadre de la formation en développement informatique à l’ENI École Informatique.

Ce projet m’a permis de mettre en pratique mes compétences en développement Java, en création d’interfaces web et en conception d’une application à partir de spécifications fonctionnelles.
